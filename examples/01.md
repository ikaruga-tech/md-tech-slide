# Markdown Tech Slide 機能網羅サンプル

技術文書から高品質なスライドを生成する VS Code 拡張機能の機能ショーケースです。

- ネイティブ PowerPoint（PPTX）出力
- ヘッドレスブラウザによる高精度 PDF 出力
- 双方向スクロール連動のリアルタイムプレビュー

::: note
このスライドは md-tech-slide の全構文パターンを網羅したサンプルです。
発表者は各スライドの構成やレイアウトの再現性を確認してください。
:::

########

## 基本テキストとタイポグラフィ

スライド作成で利用可能な各種基本テキスト表現と装飾記法です。

Markdown の標準的なインライン装飾に対応しています。
**太字強調** や *斜体テキスト*、`インラインコード`、および [プロジェクトリンク](https://github.com/ikaruga/md-tech-slide) が利用可能です。

> 引用ブロック（Blockquote）もスライド上で見やすくスタイリングされます。

### 主要な特徴

- 階層化された箇条書きリスト
  - 子階層のインデント表示
  - 自動フォント縮小によるレイアウト維持
- 番号付きリストとの併用

1. 第一段階: Markdown の記述
2. 第二段階: プレビューでの確認
3. 第三段階: PPTX または PDF への出力

########

## 均等 2 カラムレイアウト

標準の `::: columns` を用いた左右均等（50:50）のスロット分割配置です。

::: columns
::: column

### 左カラム: 特徴と仕様

- Body 領域を自動的に 2 分割して配置
- 各カラム内で独立したテキストフロー
- ネイティブなテキストボックスとして描画

左右で異なるコンテキストを整理して対比する際に最適です。
:::
::: column

### 右カラム: コード実装例

```typescript
import { parseMarkdownToSlideDeck } from "md-tech-slide";

const markdown = "# Hello\n\nContent";
const deck = parseMarkdownToSlideDeck(markdown);
console.log(`Slides count: ${deck.slides.length}`);
```

シンタックスハイライトが適用されたコードブロックです。
:::
:::

::: note
均等 2 カラムレイアウトでは、左右のバランスが崩れないよう配慮されています。
:::

## 比率指定 2 カラムレイアウト（2:1）

`ratio="2:1"` オプションにより、メイン領域とサイドバー領域を表現できます。

::: columns ratio="2:1"
::: column

### メインコンテンツ（幅 2/3）

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class SlideElement:
    element_type: str
    content: str
    metadata: dict[str, str]


def process_slide(element: SlideElement) -> bool:
    """スライド要素を検証して正常性を判定します。"""
    return bool(element.content.strip())
```

コードブロックやメインとなる長文テキストを余裕を持って配置できます。
:::
::: column

### 解説・補足（幅 1/3）

- 比率の指定
  - `ratio="2:1"` や `ratio="1:2"` に対応
- 自動幅計算
  - スライド横幅に基づき正確に座標割り当て
- 柔軟な構成
  - 補足メモやパラメータ一覧の表示に活用
:::
:::

Body 領域を 3 分割し、アーキテクチャのモジュール構成や比較を明瞭に示します。

::: columns

### 1. Parser 層

Markdown AST 解析と Slide IR（中間表現）への抽象化を行います。

- markdown-it
- frontmatter (YAML)
- fenced divs
:::
::: column

### 2. Generator 層

IR から PowerPoint 図形・テキスト枠へ変換します。

- PptxGenJS
- Shiki ハイライト

:::

### 3. Exporter 層

ファイル保存および外部ブラウザとの連携を担います。

- puppeteer-core

- 進捗通知 UI
:::

::: note
3 カラムは情報量が多くなりやすいため、箇条書きを短く保つことが推奨されます。

## データテーブルと表組み

Markdown のテーブル記法を用いた比較表の作成に対応しています。

| モジュール | 主な役割 | 出力形式 | 依存関係 |
| --- | --- | --- | --- |
| `parser` | 構文解析と IR 生成 | `SlideDeck` オブジェクト | `markdown-it` |
| `generator` | スライド座標配置と描画 | `.pptx` バイナリ | `pptxgenjs`, `shiki` |
| `renderer` | プレビュー用 HTML 生成 | HTML / CSS 文字列 | なし（Vanilla CSS） |
| `export` | ファイル出力とブラウザ印刷 | `.pptx` / `.pdf` | `puppeteer-core` |

表組みの各セルは、PowerPoint 側ではネイティブの Table オブジェクトとして出力されます。
行や列の追加・編集も PowerPoint 上で自由に行えます。

## まとめと次のステップ

md-tech-slide は技術スライド作成の効率と品質を両立します。

- PowerPoint 側で再編集可能なネイティブ出力
- 開発者向けの快適な Markdown 記法とスニペット支援
- エディタ横でのリアルタイムプレビューと双方向スクロール

### 提供コマンド一覧

- `md-tech-slide.openPreview`: プレビューパネルの表示
- `md-tech-slide.exportPPTX`: PowerPoint（PPTX）へのエクスポート
- `md-tech-slide.exportPDF`: PDF スライドへのエクスポート
